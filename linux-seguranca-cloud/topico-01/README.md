## Diferença entre VM, VPS e infraestrutura em nuvem
Uma VM emula um computador completo em software, enquanto que uma VPS é uma VM isolada com recursos dedicados em um servidor compartilhado.Por fim, a infraestrutra em nuvem engloba todas essa redes de servidores e recursos virtuais oferecidos sob demanda via internet.
